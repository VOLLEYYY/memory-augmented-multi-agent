# LangGraph 简介

LangGraph 是一个用于构建**有状态、多智能体（multi-agent）**应用的开源框架，由 LangChain 团队开发。它的核心思想是把大语言模型（LLM）应用的工作流建模成一张**图（graph）**，由**节点（node）**和**边（edge）**组成。

## 核心概念

### 节点（Node）
节点是图中的计算单元，通常对应一个 Python 函数或一个可调用对象。节点接收当前的图状态（state），处理后返回更新后的状态。例如在问答系统中，可以有一个「检索节点」负责从知识库检索资料，一个「生成节点」负责调用模型生成回答。

### 边（Edge）
边定义了节点之间的执行顺序，即控制流。边分为普通边（固定顺序）和**条件边（conditional edge）**：条件边根据当前状态动态决定下一步走向哪个节点，从而实现分支逻辑。

### 状态（State）
状态是整个图共享的数据结构（通常是 TypedDict）。所有节点读写同一份状态，这是多智能体协作时避免「各说各话」的关键——各智能体把中间结果写回共享状态，彼此可见。

### 检查点（Checkpointer）
检查点负责持久化图的状态。按 thread_id（会话 ID）隔离不同用户/会话的状态，实现跨轮次、跨重启的「工作记忆」。

## 典型应用
- 多智能体协作：把一个复杂任务拆给多个专业子智能体，通过共享状态协调。
- 带记忆的对话：用 checkpointer 保存会话状态，用长期记忆存储跨会话沉淀。
- 可控的工作流：条件边实现路由、循环、人工介入（human-in-the-loop）。

## 与传统链的区别
LangChain 的 Chain 是线性的「输入→输出」，而 LangGraph 是有向图，支持循环、分支和状态持久化，更适合构建复杂、可控、可观测的智能体系统。

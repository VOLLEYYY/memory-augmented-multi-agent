# RAG（检索增强生成）入门

RAG 是 Retrieval-Augmented Generation 的缩写，即「检索增强生成」。

## 核心思想

RAG 让大语言模型在回答问题之前，先从外部知识库检索相关信息，
再把检索到的内容作为上下文一起送入模型，从而减少幻觉、增强回答的准确性。

## RAG 的五个环节

1. 文档加载：读取 PDF、Word、Markdown 等格式的文档。
2. 文档分块：把长文档切成固定大小的块，块与块之间保留重叠。
3. 向量嵌入：把文本块转换为向量表示。
4. 向量检索：计算问题向量与文档向量的相似度，取最相关的 top_k 个。
5. 生成回答：把检索结果和用户问题一起交给大模型生成答案。

## 为什么需要分块重叠

分块太大检索不精确，分块太小语义不完整。
块与块之间保留 overlap（重叠），可以防止关键信息被切断。

## 常见检索策略

- 基础检索：直接用问题向量搜索。
- 多查询扩展：用 LLM 生成多个变体问题同时搜索。
- 假设文档嵌入：让 LLM 先假想一个答案，再用假想答案去搜索。

## 向量数据库

向量数据库专门用于存储和检索高维向量，常见的有 Qdrant、Milvus、FAISS 等。
它通过近似最近邻搜索算法，在海量向量中快速找到最相似的若干个。

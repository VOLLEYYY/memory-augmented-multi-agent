# 售后服务流程

## 服务渠道
- 在线客服：App / 官网右下角「在线客服」，服务时间 9:00-22:00
- 电话客服：400-800-1234，服务时间 9:00-18:00
- 智能客服：7×24 小时在线，覆盖常见问题自助解答

## 工单流程
1. 提交：用户描述问题（支持文字、图片、视频）
2. 分类：智能客服自动识别问题类型并路由（退换货 / 维修 / 物流 / 投诉）
3. 处理：对应专员跟进，复杂问题升级处理
4. 关闭：问题解决后关闭工单，用户可评价

## 退换货流程
1. App「我的订单」→ 申请售后
2. 选择「退货退款」或「换货」
3. 提交原因与凭证，等待审核
4. 审核通过后寄回（质量问题商家承担运费）
5. 仓库质检后退款或补发新货

## 维修流程
- 寄修：App 提交维修申请 → 生成维修单 → 寄回 → 检测报价 → 用户确认 → 维修 → 寄回
- 上门维修：智能门锁、扫地机器人等大件可申请上门（需确认服务范围）
- 维修周期：一般 5-15 个工作日，以客服告知为准

## 投诉与升级
- 对处理结果不满意，可在工单内选择「升级处理」
- 升级后由客服主管 24 小时内回电跟进
- 仍无法解决，可申请平台介入或向 12315 投诉

## 服务时效承诺
- 智能客服响应：秒级
- 人工客服响应：高峰期不超过 3 分钟
- 审核时效：退换货审核 1-2 个工作日
